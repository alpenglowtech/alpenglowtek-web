Architecture Overview

アーキテクチャレベルで、データフローを再定義する

ウェアラブルデバイス、センサーノード、産業用エッジ機器において、消費電力1ジュール、遅延1ミリ秒の差が製品競争力を左右します。

従来のデジタルAIアーキテクチャでは、演算処理における頻繁なデータ移動が性能と消費電力を左右する最大のボトルネックとなってきました。電力に制約のある環境では、パラメータの最適化だけでは不十分であり、アーキテクチャレベルでデータフローそのものを再定義する必要があります。

ANIX が採用するメモリ内演算（Computing-in-Memory, CIM）技術は、ストレージセル内でデータをそのまま処理することで、メモリと演算ユニット間のボトルネックを打破し、データ移動に伴う冗長な電力消費とエネルギーロスを根本から排除します。

IP Licensing

IP ライセンスで、チップ統合を加速する

ANIX は現在 IP 形式でのみ提供しており、IC 設計チームが自社のチップ設計にコア演算アーキテクチャを直接統合できます。

ANIX はモジュール化された IP プラットフォームであり、ソフトウェア層とハードウェア層の各モジュールを必要に応じて自由に組み合わせることができます。IC 設計チームは自社のチップアーキテクチャに応じて、必要な IP モジュールを選択して統合できます。

IP ライセンスに加えて、SoC 統合設計サービスもご提供しており、IP の導入からチップ統合までの一連のプロセスをお客様に代わって完遂します。ゼロから自社で構築する必要はありません。
